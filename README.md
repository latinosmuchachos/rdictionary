# rdictionary
My first app on Rust. It's dictionary for learning new words on another language. 

I am writing this application to learn the rust language.
Sometimes I use AI agents to build a code writing plan. That's why I can't always choose the best way to do something. If you think that something can be improved or a more idiomatic approach can be used, please send a pull request.


I haven't done any optimization checks yet as part of this project. Possible places for optimizations are marked with a comments 'TODO(optimization)'.
